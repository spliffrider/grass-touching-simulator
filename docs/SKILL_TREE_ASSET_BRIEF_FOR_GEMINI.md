## Global Style

- 96x96 px PNG
- Transparent background
- Bright readable pixel-art / 16-bit icon style
- No text inside any icon
- Strong silhouette, readable at 40x40 px
- Cozy emerald meadow fantasy palette
- Use grass lime, emerald green, gold highlights, cream highlights, and subtle dark outlines
- Match the game tone: cute, playful, slightly magical, not realistic
- Avoid dark muddy icons, tiny details, photorealism, flat emoji style, or UI text
