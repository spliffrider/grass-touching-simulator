# Skill Icon Asset Request

Generate skill-tree icons for Grass Touching Simulator.

## Output Folder

Put every generated PNG here:

```text
public/assets/ui/skills/
```

Create the folder if it does not exist.

## Format

- File type: transparent PNG
- Canvas size: 64x64
- Style: cozy pixel art, matching the existing grass/shop/world assets
- Background: transparent only
- Text: no words, no letters, no numbers baked into the image
- Framing: centered icon with 4-8 pixels of padding
- Readability: must still read clearly when displayed around 38-48 px
- Palette: bright meadow greens, warm sunlight yellows, soft sky blues, dirt browns, clover greens, gentle pinks only where thematically useful
- Avoid: realistic rendering, gradients, big drop shadows, UI frames, badges, labels, black backgrounds, scenery behind the icon

## Icon Concepts

- `softer-grass.png`: soft tuft of bright grass, rounded blades, gentle cushion feeling
- `faster-regrowth.png`: small grass sprout with motion streaks or quick upward growth
- `dew-appreciation.png`: grass blade with a clear dew droplet
- `barefoot-confidence.png`: simple bare foot stepping near grass, playful and cozy
- `palm-press.png`: open hand pressing gently into grass
- `two-handed-technique.png`: two small hands reaching toward a grass patch
- `mindful-contact.png`: calm grass sprout with a small zen-like circular ripple
- `lucky-clover.png`: four-leaf clover with tiny luck sparkle
- `dramatic-touch.png`: dramatic touch impact burst on grass, comic but cozy
- `satisfying-crunch.png`: crisp grass/dry leaf crunch motif with small golden flecks
- `overreaction.png`: exaggerated grass impact burst, energetic but not angry
- `fertile-soil.png`: rich dirt mound with tiny roots or sprout
- `morning-mist.png`: pale mist curls around grass blades
- `warm-sunlight.png`: small sunbeam shining onto grass
- `root-network.png`: branching roots under a grass tuft
- `perennial-patches.png`: looping regrowth arrow around a grass patch
- `dew-respecter.png`: larger dew droplet with grass and subtle sparkle
- `weather-watching.png`: small cloud/sun/weather charm above grass
- `soft-meadow.png`: tiny soft meadow patch with flowers or layered grass
- `grass-identification.png`: magnifying glass inspecting a grass blade
- `better-eyes.png`: friendly eyes or magnifier noticing rare grass sparkle
- `clover-magnet.png`: horseshoe magnet attracting clover leaves
- `premium-pasture.png`: rare golden/clover grass patch with premium sparkle

## Notes

Use hyphenated filenames exactly as listed. The game upgrade ids use underscores internally, but the asset files should use hyphens.

These will replace the current text-only skill node icons, so each image should read as a standalone symbol without labels.
